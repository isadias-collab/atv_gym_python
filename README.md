# 🏋️ GymTrack

O **GymTrack** é um aplicativo desenvolvido em **Python utilizando a biblioteca Flet**, criado para ajudar na organização e acompanhamento dos exercícios realizados durante os treinos.

A aplicação permite adicionar exercícios, informar a quantidade de séries e repetições, marcar exercícios como concluídos e removê-los da lista.

## 🎯 Objetivo

O objetivo do projeto é facilitar a organização do treino e acompanhar o progresso dos exercícios realizados durante a atividade física.

Além disso, o projeto foi desenvolvido para colocar em prática os conhecimentos aprendidos sobre a biblioteca **Flet**, como layouts, formulários, listas dinâmicas, gerenciamento de estado e atualização da interface.

## ⚙️ Funcionalidades

- ➕ Adicionar novos exercícios
- 🔢 Informar séries e repetições
- ✅ Marcar exercícios como concluídos
- 🗑️ Excluir exercícios
- 📊 Visualizar o progresso do treino
- 📈 Barra de progresso que é atualizada conforme os exercícios são concluídos
- ⚠️ Aviso caso algum campo não seja preenchido
